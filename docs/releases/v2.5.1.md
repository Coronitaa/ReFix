ReFix 2.5.1 fixes problems found in 2.5.0, mostly in uninstalling and in the new Linux support.

### Uninstall
- **Windows (`Uninstall_ReFix.bat`)**: the game's own `winmm.dll` / `winhttp.dll` were restored and then deleted a few lines later. Only ReFix's copies are removed now.
- **Linux (`AutoDeploy.sh --uninstall`)**: ReFix's `winmm.dll` / `winhttp.dll` stayed in the game folder when the game had none of its own, so the game kept loading ReFix. They are removed now, together with `.refix_launch_options.txt`. When both exist, the game's own `steam_api64.dll` wins over the stock copy ReFix Online adds.
- Remove `WINEDLLOVERRIDES` from the game's Steam launch options after uninstalling on Linux.

### LAN
- Players who crash or lose connection leave the lobby again. In 2.5.0 every lobby member was kept alive forever.
- `CustomBroadcasts` (ZeroTier / Tailscale / Hamachi addresses) now also reach the discovery port in Unreal Engine games. 2.5.0 sent the beacons to the game port instead.
- **ReFix Offline LAN** is back to the 2.3.2 build, as described in the README. 2.5.0 had replaced its 64-bit DLL with the new one.

### Linux / Wine
- ReFix no longer counts its own `SteamAppId` as "Steam is running" under Wine. Lutris, Heroic and Bottles without Steam fail fast again instead of waiting.
- The Linux deploy test (`tests/test_autodeploy_linux.sh`) now runs with plain `bash` and checks the uninstall. It was tested in WSL (Ubuntu 24.04), and ReFix's test programs were run under Wine 9.0. It has not been tried with games on a real Linux PC.

### Overlay (Windows)
- The X11 focus changes from 2.5.0 apply only under Wine. On Windows the overlay stays out of the taskbar and Alt+Tab again, and dragging inside the overlay works again.

Google Drive and OneDrive sync stay built in, as in 2.5.0.
