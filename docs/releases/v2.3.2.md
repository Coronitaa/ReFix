ReFix 2.3.2 is a compatibility update for ReFix Online and the ReFix LAN overlay.

### ReFix LAN overlay
- **No more crash at startup in games that patch DXGI:** when another module of the game has already patched DXGI's factory, the overlay skips DirectComposition and draws through a layered window. Before, the game could crash inside `dxgi.dll` as soon as the overlay started.

### ReFix Online
- **Free-to-play games keep their real AppID:** AutoDeploy (Windows and Linux) asks the Steam store whether the game is free to play. If it is, the game runs under its real AppID instead of Spacewar (480), so its own backend accepts the Steam login. If the store can't be reached, it still uses 480.
- **Install folder fallback:** `ISteamApps::GetAppInstallDir` returns the game's folder when Steam has none for the real AppID. Games that build a path from it at startup no longer fail to initialise Steamworks.
