ReFix 2.2.0 adds game mods: signed packages that ReFix loads for one game, installed by AutoDeploy when the game has one. The first is a full CS:GO 1.37 (2019) LAN mod. This release also brings an in-game store, overlay support under Proton, a cleaner install that keeps only one backup of each DLL, and fixes for Photon Fusion and Unity IL2CPP games.

### Game mods and the Mod SDK
- ReFix loads `.rfmod` packages from the game's `refix_mods` folder. Every package is Ed25519-signed and every file is SHA-256 checked. Native mods must carry the ReFix release signature. Community mods run as WebAssembly in a sandbox, with no access to files, the Windows API or sockets. A mod that faults is unloaded and its patches are rolled back. The game keeps running.
- AutoDeploy (Windows and Linux) checks `refix_mods/catalog.tsv`. When there is a mod for the game, it installs it from the release zip, or downloads it from the repository and checks it against the catalog's SHA-256. The uninstallers remove the mod and restore every game file it changed.
- `refixmod.exe` makes keys and packs, signs, verifies and inspects packages.
- Mod SDK guide: [docs/wiki/Mod-SDK.md](https://github.com/Coronitaa/ReFix/blob/main/docs/wiki/Mod-SDK.md).

### CS:GO 1.37 LAN mod
- **Inventory:** the emulated Game Coordinator keeps it on disk, per profile.
  - Skins show their real finish, wear and seed.
  - Market & Skins in the ReFix overlay grants any item, including stickers, patches, graffiti, music kits, collectibles and operation passes, with previews.
- **Cases and capsules:** cases drop from their real loot lists, with knives and gloves as rare specials. Sticker capsules give stickers and graffiti boxes give graffiti.
- **Stickers:** apply and scrape on any weapon.
- **Service medals:** "Get service medal" grants the medal and upgrades its level.
- **Operation Shattered Web:**
  - All 16 weeks are playable, including the 12 that the 2019 build ships locked. ReFix adds them to the game files and keeps `.refix_orig` backups.
  - Missions start from the operation menu.
  - Points earned at the end of a match add up mission by mission, complete missions and award stars. Progress is saved per profile, and each player's points reach their own PC.
- **Play on the LAN:**
  - The play menu's **LAN SERVER** button hosts a match. **START** finds open matches on the LAN.
  - LAN rooms let friends gather before a match.
  - Players join each other from the overlay or the friends list.
- **Every game mode on the LAN server:** Competitive, Casual, Wingman, Weapons Expert, Deathmatch, Arms Race, Demolition, Danger Zone, Guardian and Co-op Strike, plus the War Games Flying Scoutsman, Stab Stab Zap, Trigger Discipline, Headshots, Hunter-Gatherers and Heavy Assault Suit. You also set the map, players, rounds, round time, money, bots, rules and a password.
- **Prime:** Prime status and operation passes are stored per profile.
- **Language:** the overlay is in English and Spanish.

### In-game store
- Games that sell items through Steam microtransactions show a ReFix purchase dialog instead of failing. Nothing is charged.
- Mono runtime emulation for Unity games.

### Overlay
- **Proton / Wine:** the ReFix overlay now shows. Wine has no DirectComposition, so the overlay falls back to a layered window. `[Overlay] Composition = false` forces that mode on Windows too ([#4](https://github.com/Coronitaa/ReFix/issues/4)).
- Fixed overlay drawing artifacts and double scaling.

### ReFix LAN
- Rich presence is shared between players on the LAN, so friends lists show what everyone plays and let them join.
- Fixed Photon Fusion timeouts (SD-014) and dropped packets.
- Unity IL2CPP games: generic hooks and a bypass for their reporting service.
- Fixed save isolation between profiles.

### Install
- 32-bit games now keep a single backup, `steam_api_original.dll`. Older installs also had a copy named `steam_api_o.dll`; AutoDeploy merges it into the single backup.
- `ReFix.ini` comments written by AutoDeploy are in English.
- The release zip includes `DLC_Unlocker.bat` and the `refix_mods` folder.
- Removed the old 2.0 release copy, test leftovers and development dumps from the repository.

### DLC unlocker
- `DLC_Unlocker.bat` writes the SmokeAPI 4 config. Before, the bundled SmokeAPI 4.1.3 ignored the old keys ReFix wrote, so "none" and a custom list unlocked everything. Games whose DLC list Steam does not return in full, like Arma 3, now get the list from the Steam Store ([#1](https://github.com/Coronitaa/ReFix/issues/1)).

### Mod SDK fix
- WebAssembly mods can import `refix_get_time_ms`. It was registered with a 32-bit return type and failed to link.

### Known limits
- CS:GO mission points come from the host's game server at the end of a match. This has not been checked yet in a match with two human players.
- CS:GO Co-op Strike and Guardian missions need two players, as in the original game.

### Update
Run `AutoDeploy.bat` (Windows) or `bash AutoDeploy.sh` (Linux) on the game folder again. Everyone who plays together needs ReFix 2.2.0.
