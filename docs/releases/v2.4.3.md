ReFix 2.4.3 makes installs smaller and fixes how AutoDeploy reads games it already installed on.

### AutoDeploy
- **Photon Fusion server only where it's needed:** the Fusion Shared server (about 7 MB) was copied into every game. Now only Photon Fusion games get it, and redeploying removes it from the others.
- **Better detection on reinstalls:** that server carries Photon and Fusion files, and AutoDeploy took them for the game's own. A redeploy could then treat any game as a Photon Fusion game, picking ReFix's Photon emulator and port 27015 for games that don't use them. ReFix's own files are now ignored.
- **Game folder detection:** ReFix's own helper programs are no longer mistaken for the game's .exe.

Includes everything from 2.4.2 (Online Legacy saves kept next to the game, overlay Autosync).
