ReFix 2.4.4 adds automated EasyAntiCheat (EAC) proxy deployment, fixes Photon Fusion lobby hosting, and throttles repetitive IL2CPP logging.

### Anti-Cheat & EAC
- **Automatic winhttp.dll proxy deployment:** games using EasyAntiCheat (EAC) or `start_protected_game.exe` are now detected during AutoDeploy, automatically deploying the forwarded `winhttp.dll` proxy next to the game executable.
- **EOS Anti-Cheat client & server emulation:** generic stubs for `EOS_AntiCheatClient` and `EOS_AntiCheatServer` allow protected games to initialize without anti-cheat services aborting.
- **Uninstaller update:** uninstallation scripts now restore `winhttp_original.dll` and remove the ReFix proxy cleanly.

### Unity / Photon Fusion & IL2CPP
- **PhotonAuth hosting fix:** resolved infinite loading screen when hosting private matches (e.g. Among Us 3D). `AirlockPeer.PhotonAuth` now bypasses online custom authentication ticket validation in LAN/offline play, letting `NetworkRunner.StartGame` spin up local simulation immediately.
- **FTUE direct jump:** bypassed initial tutorial interruption flow to proceed directly to the main menu.
- **Log throttle:** throttled per-frame internet check logging that caused `ReFix.log` to balloon into tens of megabytes within seconds.
