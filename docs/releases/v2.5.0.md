ReFix 2.5.0 brings full, verified native support for Linux systems running Windows games through Proton, Wine, and Steam Play, resolves Virtual LAN / VPN lobby connection issues (ZeroTier, Tailscale, Hamachi - Issue #20), and prevents mid-game session disconnects / overlay focus issues in cross-platform titles (Among Us 3D / Photon - Issue #25).

### Linux, Proton & Wine Full Compatibility
- **Automated Proton Deployment (`AutoDeploy.sh`)**: Added support for Option 3 (`online` via `winmm.dll`), auto-generated `.refix_launch_options.txt` (`WINEDLLOVERRIDES="winmm,winhttp=n,b" %command%`), and verified backup/restore automation via `tests/test_autodeploy_linux.sh`.
- **Fast-fail non-Steam Wine prefixes**: Runtime environment detection (`ntdll.dll!wine_get_version`, `STEAM_COMPAT_*`) bypasses 30s Steam client startup hangs under standalone Wine/Lutris/Heroic/Bottles prefixes.
- **X11 / XWayland Overlay Focus**: Replaced `WS_EX_TOOLWINDOW` with explicit parent-child window hierarchy (`GWLP_HWNDPARENT`), implemented `WM_MOUSEACTIVATE` (`MA_ACTIVATE`), and proper mouse capture release (`ReleaseCapture()`, `SuspendGameRawInput()`). Recreates ImGui DX11 device objects upon DXVK resolution switches.

### Virtual LAN & VPN Lobby Routing (Issue #20)
- **Config Section Unification**: Wire `CustomBroadcasts` parsing in `unreal_steam_emu.cpp` to prioritize `[Network]` before falling back to `[Unreal.Networking]` and `custom_broadcasts.txt`.
- **Targeted Subnet Beaconing**: Eliminated the legacy 16-port loop (`47584..47599`) when sending to custom broadcast endpoints, targeting strictly the designated port and avoiding `WSAENOBUFS` socket queue overflow on virtual network interfaces.
- **Firewall Whitelisting**: Added automatic subnet admission for Tailscale CGNAT (`100.64.0.0/10`) and LogMeIn Hamachi (`25.0.0.0/8`).

### P2P ARQ Keep-Alive & Active Session Protection (Issue #25)
- **Activity Tracking on Data & ACKs**: `LanTransport::ProcessInboundWirePacket` now treats inbound `DataAck` and `DataUnreliable` packets as active transport traffic, touching peer timestamps.
- **Stale Peer Pruning Protection**: Extended idle timeouts from 15s to 60s, and added active lobby/session protection guards in `LanCoreImpl::Tick` preventing ARQ transport table eviction during quiet network phases.
- **Photon Unresolved Peer Fallback**: Triggers immediate broadcast queries when attempting to transmit to unresolved peers in `pn_lan_backend.cpp`.

### Cloud Save Sync Integration (Google Drive & OneDrive)
- Production binaries include built-in, obfuscated OAuth integration for Google Drive and OneDrive cloud save synchronization.
- Client credentials are embedded securely using XOR cipher unscrambling, keeping sensitive keys out of the git repository.
