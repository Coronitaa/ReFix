ReFix 2.4.2 fixes lost progress in ReFix Online Legacy and adds autosync to profile syncing.

### Online Legacy
- **Saves that never stuck:** games saved to Steam Cloud under Spacewar's AppID, which only holds about 4 KB and is shared by every game using it. Bigger saves failed, so some games started from scratch every launch or said the save file was corrupted. Steam Cloud files are now kept next to the game, in `saves\SteamCloud`. Small saves that already lived in the Spacewar cloud are copied over the first time the game reads them.

### Overlay
- **Autosync** (Settings > Syncing, on by default): when the game saves, ReFix uploads the profile a few seconds after it finishes writing, at most once every 5 minutes, so a crash or a quick switch to another PC doesn't lose the latest progress.
