ReFix 2.3.1 updates the ReFix LAN overlay and the CS:GO LAN & Economy Overhaul mod (`v1.1.0`) so that CS:GO achievements and the mod coexist seamlessly in the overlay, custom LAN host configurations are strictly respected across all game modes, and game mode defaults load automatically.

### CS:GO achievements & overlay coexistence
- **Local CS:GO achievement schema:** CS:GO (`AppID 730` and standalone legacy `4465480`) now loads all 167 official achievements directly from the installed game files (`csgo\resource\csgo_english.txt` and `csgo_spanish.txt`), paired with local achievement icons from `csgo\materials\panorama\images\icons\achievements\`.
- **Cross-AppID progress sync:** unlocked achievements, progress, and stats are unified between classic CS:GO (`730`) and standalone legacy (`4465480`).
- **Overlay layout (`Shift+Tab`):** the left column always keeps both the **CS:GO LAN** card and the **Achievements** card visible together, adding a scrollable room list when vertical height is tight while keeping the bottom action buttons pinned.

### CS:GO LAN Server configuration & mode defaults (`refix.csgo.lan_overhaul` v1.1.0)
- **Custom player limits (`2..64` players):** overrides `maxplayers` in any game mode (such as 32-player Competitive or custom Wingman) via `tier0.dll`'s `ICommandLine::AppendParm("-maxplayers_override")` and a runtime-signature-aware `IGameTypes::GetMaxPlayersForTypeAndMode` vtable hook across `server.dll`, `matchmaking.dll`, and `client.dll`.
- **Persistent match rules (`refix_lan_host.cfg`):** writes custom match rules (`mp_maxrounds`, `mp_roundtime`, `mp_roundtime_defuse`, `mp_roundtime_hostage`, `mp_startmoney`, `mp_maxmoney`, `mp_friendlyfire`, `mp_overtime_enable`, `sv_cheats`, `sv_password`, `sv_visiblemaxplayers`, `mp_limitteams 0`, `mp_autoteambalance 0`, `mp_humanteam any`, `bot_quota`, `bot_difficulty`) to `csgo\cfg\refix_lan_host.cfg`, chains it at the end of `gamemode_*_server.cfg`, and re-applies it on `ServerHello` so standard `gamemode_*.cfg` scripts never overwrite host settings.
- **Configurable warmup time (`0..300 s`):** added a **Warmup time (sec)** slider to the LAN Server UI. Setting it to `0 s` disables warmup completely (`mp_do_warmup_period 0`, `mp_warmup_end`); setting a custom duration sets both `mp_warmuptime` and `mp_warmuptime_all_players_connected` so the timer is not cut short when bots or players finish connecting.
- **Per-mode default presets & Panorama tab sync:** clicking any mode in the LAN Server window—or opening the LAN Server window from a mode tab in CS:GO's Panorama Play menu—automatically loads that mode's official default configuration (slots, rounds, round time, warmup time, starting/max money, friendly fire, overtime, bots, and bot difficulty).
