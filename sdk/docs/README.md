# ReFix Mod SDK

The SDK guide lives in [docs/wiki/Mod-SDK.md](../../docs/wiki/Mod-SDK.md): how ReFix loads mods, the
manifest, capabilities and trust, native and WebAssembly mods, packing and signing with `refixmod`,
the mod catalog AutoDeploy installs from, and a walkthrough of the CS:GO mod.

This folder holds the headers (`include/`), language bindings (`bindings/`) and examples (`examples/`).
